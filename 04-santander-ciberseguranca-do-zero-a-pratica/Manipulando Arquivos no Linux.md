# Navegando pelo sistema de arquivos

lista de comandos aprendidos:

1. pwd (Print Working Directory): Exibe o caminho completo da pasta em que estou
2. cd (Change Directory): mudar de diretório (pasta)
3. ls (List): Lista arquivos e diretórios no local atual
4. ls |(pipe) more: Lista os arquivos conforme eu aperto Enter, mais fácil de procurar
5. touch: criar um arquivo vazio ou atualizar a data de modificação de um arquivo existente
6. cd ~: entra na pasta do usuário
