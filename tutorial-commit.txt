1° - Entrar na pasta:
cd "C:\Users\dania\OneDrive\Desktop"

2° - Verificar se está na pasta correta (opcional):
pwd

3° - Inicializar repositório:
git init

4° - Conectar ao repositório do GitHub:
git remote add origin URL_DO_REPOSITORIO

5° - Adicionar arquivos:
git add .

6° - Criar primeiro commit:
git commit -m "primeiro commit"

7° - Definir branch principal:
git branch -M main

8° - Enviar para o GitHub (primeira vez):
git push -u origin main

9° - Atualizar após mudanças:
git add .

10° - Criar novo commit:
git commit -m "descrição da alteração"

11° - Enviar alterações:
git push

12° - (Opcional) Auto commit manual rápido:
git add . && git commit -m "auto commit" && git push
